# Oopz 按键说话

给 [Oopz 网页版](https://web.oopz.cn) 加上按键说话（Push-to-Talk）。网页版目前只支持自由发言，这个项目补上了：

- **全局快捷键**：游戏或其他程序在前台时也能按住说话。支持键盘按键、组合键、鼠标中键和侧键
- **释放延迟**：松开按键后过一会儿再关麦，句尾不会被吞掉
- **设置就在 Oopz 里**：出现在「设置 → 语音设置」原本写着"暂不支持按键说话"的位置
- **麦克风实际状态**：顶栏麦克风图标旁有一个小圆点，显示声音是否真的在发送

> 非官方项目，与 Oopz 官方无关。

## 组成

| 文件 | 作用 |
| --- | --- |
| `OopzPtt.exe` | 本地助手，常驻托盘，负责监听全局按键。单文件原生程序，不需要安装任何运行库 |
| `extension/` | 浏览器扩展（推荐），把功能注入 Oopz 网页 |
| `oopz-ptt.user.js` | 油猴脚本，不想装扩展时用（与扩展二选一，也可以都装） |

推荐只装一种。两个同时安装也能正常工作：只有先加载的一份生效，另一份自动让位并释放自己的连接，不会出现重复面板或双份连接。支持 Edge、Chrome 等 Chromium 内核浏览器，本地助手仅支持 Windows 10/11 x64。

## 安装

1. 下载 `OopzPtt-x.y.z-win-x64.zip`，解压到一个固定的位置。国内访问 GitHub 较慢时，用下面的镜像地址：

   | 来源 | 地址 |
   | --- | --- |
   | GitHub（官方） | <https://github.com/IOL0ol1/oopz-ptt/releases/latest> |
   | 镜像 1（推荐） | <https://ghfast.top/https://github.com/IOL0ol1/oopz-ptt/releases/latest> |
   | 镜像 2 | <https://gh-proxy.com/https://github.com/IOL0ol1/oopz-ptt/releases/latest> |
   | 镜像 3 | <https://ghproxy.net/https://github.com/IOL0ol1/oopz-ptt/releases/latest> |

   在镜像页面上找到对应版本的 `OopzPtt-x.y.z-win-x64.zip` 下载即可。油猴脚本的 `@downloadURL` / `@updateURL` 已指向镜像 1，自动更新不需要访问 GitHub。
2. 运行 `OopzPtt.exe`。程序没有代码签名，第一次运行时 Windows 可能提示"已保护你的电脑"，点「更多信息 → 仍要运行」。之后它会出现在托盘，并自动打开 Oopz 网页版。

   如果双击没反应、或提示"此应用已被阻止"，是 Windows 给压缩包里的文件打了「来自 Internet」标记：右键 `OopzPtt.exe` → 属性 → 勾选底部的「解除锁定」→ 确定，再运行即可。
3. 安装扩展或油猴脚本 —— **任选一种即可，两个都装也不会冲突**：

   > **优先只装一种。**
   >
   > 两者注入的是同一份页面脚本。从 0.1.5 起做了共存处理：同时安装时只有先加载的一份生效，另一份自动让位并释放自己已经建立的连接，不会出现重复面板，也不会多占一条助手连接。不过多装一份没有额外收益，保留一种即可。

   **方案 A：浏览器扩展（推荐，免每次授权）**
   - 打开 `edge://extensions`（Chrome 为 `chrome://extensions`），打开「开发人员模式」
   - 点「加载解压缩的扩展」，选择解压出来的 `extension` 文件夹
   - 装好后需要刷新已经打开的 Oopz 页面才会生效

   **方案 B：油猴脚本（不想装扩展时用）**
   - 先安装 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)
   - 打开 `oopz-ptt.user.js` 安装。新版 Chrome / Edge 需要在油猴扩展的详情页里打开「允许用户脚本」
   - 第一次连接时浏览器会询问是否允许 web.oopz.cn 访问本设备上的应用，选「允许」
4. 刷新 Oopz 网页，进入「设置 → 语音设置」，在「语音输入模式」选「按键说话」，然后按下想用的按键。

想开机就能用，在托盘菜单里勾选「开机自动启动」。

## 使用

顶栏麦克风图标右下角的小圆点：

| 颜色 | 含义 |
| --- | --- |
| 绿 | 正在发送声音，外圈光晕随音量大小变化 |
| 灰 | 按键说话待机，按住快捷键才会发送 |
| 红 | 已在 Oopz 中关闭麦克风 |

只有绿点才有外发光，光晕的半径和亮度跟着实际发送的音量走。灰点和红点不发光，避免把"待机"或"已闭麦"误看成一圈在说话。

- 语音设置页「语音输入模式」那一行会被替换成「自由发言 / 按键说话」两个可点选项，点一下立即切换，不用再看到「网页端不支持」。
- 快捷键按钮：左键点击重新录制，右键清除；录制时按 Esc 取消。单独按一下 Ctrl、Shift、Alt 会绑定这个修饰键本身，左右键分开识别。
- 释放延迟可设 0 到 1000 毫秒。
- 右键点麦克风图标会弹出 Oopz 自己的语音菜单（竖排，含回声消除、AI 降噪等），脚本面板会自动让开，不会和它叠在一起。
- 打开 Oopz 时，页面中央的活动推广浮层和首页横幅广告会被直接屏蔽（拦截 `advertisement/v2/list` 请求），不会出现。

## 常见问题

**镜像打不开 / 自动更新失效？**
镜像都是第三方公益服务，可能随时失效。下载页可换用上表里的其他镜像，或直接访问 GitHub 官方地址。油猴脚本若提示更新失败，手动打开 `oopz-ptt.user.js` 重新安装即可覆盖，设置会保留。

**别人看到我一直是开麦状态？**
按键说话只决定声音是否发出去，不会切换 Oopz 的闭麦状态，所以别人看到的仍是开麦，没按键时只是听不到声音。Discord、KOOK 的按键说话也是这样。Oopz 自带的闭麦按钮优先级更高，闭麦后按住快捷键也不会出声。

**麦克风测试也没声音？**
按键说话模式下，「麦克风测试」同样要按住快捷键，测试听到的就是别人听到的。

**在游戏里按键没反应？**
如果游戏以管理员身份运行，普通权限的程序收不到游戏在前台时的按键。在托盘菜单里选「以管理员身份重新启动」。

**本地助手没运行会怎样？**
快捷键只在 Oopz 页面处于前台时有效。

**语音设置里没看到按键说话的选项？**
Oopz 网页版整页画在一块画布上，设置项是通过识别画面位置嵌进去的。如果 Oopz 改版后识别不到，面板就不显示，以免盖错地方，欢迎提 issue。

**会不会被当成键盘记录？**
本地助手只监听 127.0.0.1:29271，只接受 Oopz 网页和浏览器扩展的连接，只上报你设置的那个快捷键的按下和松开。录制快捷键时会上报下一次按下的键。它不拦截任何按键，按键照常传给前台程序。

## 工作原理

- **网页**：在页面脚本运行前接管 `getUserMedia`。按键说话模式下，麦克风采集轨道实际的 `enabled` 等于「Oopz 自己设置的值」和「是否按着快捷键」两者同时成立；Oopz 读到的仍是它自己设置的值，所以不干扰它原有的闭麦逻辑，Agora 和 TRTC 两套语音通道都适用。设置面板和状态圆点通过读取 Flutter 画布的像素来定位。
- **绿点光晕**：用 `AudioContext` 分析实际在发送的那一路麦克风轨道，把电平映射成圆点外圈 `box-shadow` 的半径与透明度。只分析 want 为真且闸门放行的轨道，所以静音或未按键时电平为 0，不会出现"没出声、光晕却在跳"。
- **本地助手**：用 Raw Input 在后台接收键盘和鼠标输入，释放延迟在助手里计时（浏览器会降低后台标签页定时器的精度），再通过 WebSocket 通知网页。
- **连接方式**：扩展由后台 Service Worker 连接助手，网页本身不需要访问本机的权限；油猴脚本只能由网页直接连接，所以浏览器会询问一次。

## 构建

需要 .NET 10 SDK，以及 Visual Studio 或 Build Tools 的「使用 C++ 的桌面开发」工作负载（Native AOT 链接需要 MSVC）。

```powershell
pwsh scripts/build.ps1
```

产物输出到 `dist/`。推送 `v*` 标签时，GitHub Actions 会自动构建并发布 Release。

本地助手的设置保存在 `%APPDATA%\OopzPtt\settings.json`，日志 `host.log` 在同一目录。
